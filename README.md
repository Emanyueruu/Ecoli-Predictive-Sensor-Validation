# Ecoli-Predictive-Sensor-Validation
A benchmark study evaluating the predictive variance of XGBoost and AdaBoost on highly constrained environmental datasets.

This is the code and data for a mini research requirements. The dataset only had 80 rows, so this project is just an experiment to see how XGBoost and AdaBoost handle extreme variance in tiny water quality datasets. The Colab notebook and clean CSVs are included above.
